# HeadFirework

A Fabric mod that displays the player's head at the moment a firework explodes.
花火が爆発する瞬間に、使用したプレイヤーヘッドの持ち主の顔が浮かび上がる演出MODです。

## 特徴 / Features

- 花火ロケットは通常通り打ち上がり、爆発の瞬間にプレイヤーの頭が数秒間出現します
- 花火の形状(小玉・大玉・星型など)に応じて頭のサイズが変化します
- 爆発直後は小さく、ふわっと拡大しながら表示されます
- サーバー側にMODを入れるだけで、参加者はバニラクライアントのままでも演出・クラフトの両方を体験できます(配布不要)
- `/headfirework config` コマンド、またはクライアント側でCtrl+Jキーを押すことで開けるGUI画面から、頭のサイズなどを細かく調整できます

## クラフト方法 / How to craft

**専用の星(シェイプレス、配置は自由)**
- 火薬 ×1
- 染料 ×1〜8(爆発の色になります。複数入れると多色になります)
- プレイヤーヘッド ×1
- (任意・いずれか1つ) 業火の袋→大玉 / 羽根→星形 / 金塊→バースト
- (任意) ダイヤモンド→キラキラ効果
- (任意) 蓄光石→トレイル効果

**ロケット(シェイプレス、配置は自由)**
- 専用の星 ×1
- 紙 ×1
- 火薬 ×1〜3(個数に応じて飛翔時間が変化します)

## 必要環境 / Requirements

- Minecraft 26.2
- Fabric Loader
- **Fabric API(必須)**

## 導入について / Installation notes

サーバー側にのみ導入すれば、演出・クラフトともに参加者は追加の導入なしで体験できます。GUI設定画面(Ctrl+J)を使いたい場合のみ、クライアント側にもMODの導入が必要です。
