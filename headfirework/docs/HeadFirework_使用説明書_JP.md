# HeadFirework 使用説明書

**HeadFirework**は、専用の花火ロケットを追加するFabric MODです。爆発すると、クラフトに使ったプレイヤーヘッドの持ち主の顔が、爆発した花火の形状に応じたサイズで、小さい状態から拡大しながら出現し、しばらく表示された後にフェードアウトして消えます。

- **シングルプレイ**でも**マルチサーバー**でも同じMOD1つで動作します。サーバー(またはシングルプレイの統合サーバー)側にMODを入れるだけでよく、参加するプレイヤー側へのMOD配布は不要です。
- **クリエイティブ**・**サバイバル**両モードに対応しています。

## 必要環境

- Minecraft 26.2
- Fabric Loader
- Fabric API

## クラフト方法

### 1. プレイヤーヘッド花火の星

作業台で以下を組み合わせます(シェイプレスレシピのため配置は自由です)。

| 材料 | 必須/任意 | 効果 |
|---|---|---|
| 火薬 | 必須 | 基本材料 |
| 染料(1個以上) | 必須 | 花火の色を決定。複数個使うと複数色の爆発になる |
| プレイヤーヘッド(オーナー情報付き) | 必須 | 爆発時に表示される顔。同一プレイヤーの頭であれば複数個まとめて投入できる(頭は消費されない) |
| 業火の袋 / 羽根 / 金塊 | 任意・**いずれか1つ** | 業火の袋→大玉、羽根→星形、金塊→バースト |
| ダイヤモンド | 任意 | キラキラ効果を追加 |
| 蓄光石 | 任意 | トレイル(尾)効果を追加 |

業火の袋・羽根・金塊のいずれも使わない場合、形状はデフォルトで**小玉**になります。

プレイヤーヘッドは事前にオーナー(スキン)情報が付いている必要があります。例えば`/give <プレイヤー名> minecraft:player_head[minecraft:profile="<名前>"]`で入手したもの、またはプレイヤー設置済みの頭を回収したものが使えます。

### 2. ロケット花火

作業台で以下を組み合わせます(シェイプレス)。

- 手順1で作ったプレイヤーヘッド花火の星(同一プレイヤーの星であれば複数個まとめて投入可能。星の個数と同数の紙が必要)
- 紙(星と同数)
- 火薬(1〜3個)

火薬の個数によって飛翔時間が変わります(バニラの花火ロケットと同じ仕様。1個=短い飛翔、3個=長い飛翔)。

## 爆発時の演出

1. ロケットは通常の花火と同じように打ち上がります。
2. 爆発の瞬間、星のクラフトに使ったプレイヤーヘッドの持ち主の顔が爆発位置に出現します。
3. 顔は最初小さく表示され、短いアニメーションで**目標サイズまで拡大**します。
4. 設定された表示時間のあいだ、そのサイズを維持します。
5. 表示時間の終わり際に、**サイズが0まで縮小**していき消滅します(アイテムディスプレイには透過度の仕組みがないため、スケール変化によるフェードアウト演出として実装しています)。

表示サイズは花火の形状(小玉/大玉/星型/クリーパー/バースト)ごとに異なり、下記の方法で調整可能です。

顔の正面が向く方角(北/東/南/西)も、下記のコマンドまたはGUIで指定できます。

星・ロケットには、使用したプレイヤーヘッドの持ち主の名前が自動的に付きます(例:「Steve花火」)。頭にオーナー名が無い場合は、名称不明のプレイヤーとして表示されます。

## MODの設定方法

### ゲーム内GUI

**Ctrl+J**キーでHeadFireworkの設定画面を開けます。以下をそれぞれスライダーで調整できます。

- 小玉のサイズ
- 大玉のサイズ
- 星型/バーストのサイズ
- 表示時間(tick単位)
- フェードアウト時間(tick単位)

各スライダーの横には個別の**R**(RESET)ボタンがあり、押すとその項目だけデフォルト値に戻ります(他に変更中の項目はそのまま維持されます)。

スライダーの下には「顔の向き」ボタンがあり、押すたびに北→東→南→西と方角が循環して切り替わります。

「適用」ボタンを押すとサーバー側にコマンドとして送信され設定が反映されます(裏側は通常のコマンド送信のため、マルチサーバーでも他のプレイヤー側にMODは不要です)。

### コマンド(オペレーター/ゲームマスター権限が必要)

```
/headfirework config scale <small_ball|large_ball|star|creeper|burst> <値>
/headfirework config display_duration <tick数>
/headfirework config animation_duration <tick数>
/headfirework config fade_duration <tick数>
/headfirework config facing <north|south|east|west>
/headfirework config show
```

- `scale` — 指定した爆発形状の表示サイズを設定
- `display_duration` — 顔が表示されている合計時間(tick単位、20tick=1秒)。拡大・フェードアウトの時間も含む
- `animation_duration` — 拡大アニメーションにかかる時間
- `fade_duration` — フェードアウト(縮小)にかかる時間。`display_duration`の終わりから逆算してこの長さぶん縮小する
- `facing` — 顔の正面が向く方角(北/南/東/西)を設定
- `show` — 現在の設定値を表示

設定内容は`config/headfirework.json`に保存され、再起動後も維持されます。

## 言語について

MODはMinecraft本体の言語設定(オプション→言語)に自動的に連動します。ゲーム内で**日本語**⇔**English (US)**を切り替えると、MODの設定画面・キーバインド名・コマンドの応答メッセージも連動して切り替わります。MOD内で個別に言語を選ぶ必要はありません。

## 注意点・既知の制限

- Minecraftのアイテムディスプレイエンティティには透過度(アルファ値)を設定する仕組みが無いため、本当の意味での透過フェードには対応していません。代わりにサイズを0まで縮小することでフェードアウトを表現しています。
- マルチサーバー(専用サーバー)での動作確認はまだ限定的です。シングルプレイ(統合サーバー)では十分に動作確認済みです。

## バージョン

この説明書は**HeadFirework v1.1.2**時点の内容です。
