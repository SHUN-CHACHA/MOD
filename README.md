# SHUN-CHACHA's Minecraft Mods

このリポジトリには、複数のMinecraft MOD/プラグインのソースコードをまとめています。

## Mods / Plugins

- [HeadFirework](./headfirework/)([ダウンロード](https://github.com/SHUN-CHACHA/MOD/releases)) — Fabric MOD版。火薬+染料+プレイヤーヘッドから専用の花火の星を作り、打ち上げると爆発の瞬間にそのプレイヤーの顔が浮かび上がる演出を追加します。参加者のクライアント側にも導入が必要です。
- [HeadFirework Paper Plugin](./headfirework-paper/)([ダウンロード](https://github.com/SHUN-CHACHA/MOD/releases)) — Paperサーバー用プラグイン版。同じ演出をサーバー側だけの導入で実現できます(参加者のクライアント側の導入は不要)。
